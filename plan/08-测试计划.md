### 步骤5：测试工具使用指南

#### 5.1 Chrome + WebSocket King Online

**用途**：手动测试 WebSocket 连接、发送接收消息

**使用步骤**：
1. 安装 Chrome 插件 "WebSocket King Online"
2. 输入 URL：`ws://P4_IP/camera` 或 `ws://P4_IP/mcp`
3. 点击 Connect
4. 在 /mcp 通道发送 JSON-RPC 文本消息
5. 在 /camera 通道观察二进制帧接收

#### 5.2 idf.py monitor

**用途**：查看 ESP32 端日志

**使用步骤**：
1. 执行 `idf.py -p COMx flash monitor`
2. 观察日志中的 `[WS]`、`[CAM]`、`[MCP]` 标签
3. 完整日志复制到 `c:\Projects\Espressif_Projects\mipi_dsi\tmp_log.txt`

#### 5.3 wifi_test Python 脚本（辅助）

**路径**：`c:\Projects\Espressif_Projects\wifi_test\tools\`

| 脚本 | 用途 |
|------|------|
| `ws_echo_server.py` | PC 端起 WS 服务器做回显测试 |
| `ws_multi_client_test.py` | 模拟多客户端并发 |
| `ws_stress_test.py` | 压力测试 |

**使用前置**：需安装 Python `websockets` 库：`pip install websockets`

#### 5.4 浏览器开发者工具

- F12 → Network → WS 过滤
- 查看每帧大小、时间戳
- Console 查看应用日志
