## 二、VLM 辅助判断路线性能优化

### 2.1 问题背景
`test_yolo_phone.py`（YOLOv8 + MediaPipe 手部 + 豆包 API 混合架构）实测 API 响应时间过长，端到端达 **31.7 秒**，严重影响实时性。

### 2.2 根因分析
- **主因**：原端点 `ep-20260615144034-b5zxv` 绑定的豆包模型较重，服务端推理慢
- **次因**：YOLO + MediaPipe 持续占用 CPU，与 API 调用产生竞争
- **隐藏原因**：豆包 seed 系列模型默认启用深度思考模式（ResponseReasoningItem），消耗大量时间

### 2.3 优化措施

#### 措施1：短期 CPU 竞争优化
- YOLO 推理间隔：3 帧 → 5 帧
- API 调用期间自动暂停 YOLO 推理（`not verifier.is_processing` 条件）
- 图片压缩：JPEG_QUALITY 50→35，MAX_IMAGE_WIDTH 640→480（后恢复初始值）

#### 措施2：切换模型端点
- 原端点：`ep-20260615144034-b5zxv`（豆包 2.0 pro）
- 新端点：`doubao-seed-2-0-mini-260428`（豆包 Seed 2.0 Mini）
- 注：尝试 `doubao-seed-1.6-flash` 失败（404），改用官方文档列出的 mini 版本

#### 措施3：关闭深度思考模式
- 通过 OpenAI SDK 的 `extra_body` 参数传递火山引擎特有字段
- 参数：`"thinking": {"type": "disabled"}`
- 依据：豆包官方文档明确说明非思考模式综合表现达思考模式 85%，但 tokens 消耗仅 1/10

### 2.4 性能对比

| 配置 | 纯 API 响应时间 | 相对基准提升 |
|------|----------------|------------|
| 原端点 + 思考模式（基准） | ~10-15s | - |
| 原端点 + 思考模式 + CPU 优化 | 11.2s（含 YOLO） | -65% |
| doubao-seed-2-0-mini + 思考模式 | 5.46s | -63% |
| **doubao-seed-2-0-mini + 关闭思考** | **2.31s** | **-85%** |

### 2.5 最终配置选择
经用户实测对比，`test_yolo_phone.py` 最终保留 `ep-20260615144034-b5zxv`（豆包 2.0 pro）端点 + 关闭深度思考模式，用户反馈"效果不错"。其余测试文件统一使用 `doubao-seed-2-0-mini-260428`。

## 五、手部检测冷启动问题修复

### 5.1 问题现象
用户反馈："首次手部出现在画面内时识别不到，只有首次识别到后才会开始持续识别"。

### 5.2 根因分析
MediaPipe HandLandmarker 有 3 个独立阈值，原配置全部为 0.5：
- `min_hand_detection_confidence`：首次检测阈值（高，难触发）
- `min_hand_presence_confidence`：手部存在判断阈值
- `min_tracking_confidence`：跟踪阈值（一旦锁定就容易维持）

拿手机时手部姿态不标准 + 部分遮挡，难以达到 0.5 的首次检测阈值，导致冷启动困难。

### 5.3 优化方案（方案 A：推荐）
| 参数 | 原值 | 新值 | 说明 |
|------|------|------|------|
| `HAND_MIN_DETECTION_CONFIDENCE` | 0.5 | **0.3** | 降低首次检测门槛 |
| `HAND_MIN_PRESENCE_CONFIDENCE` | 0.5（复用） | **0.3** | 新增独立常量 |
| `HAND_MIN_TRACKING_CONFIDENCE` | 0.5 | 0.5 | 保持稳定跟踪 |

### 5.4 代码改动
- 新增配置常量 `HAND_MIN_PRESENCE_CONFIDENCE`
- `HandDetector.__init__` 中 `min_hand_presence_confidence` 改用独立常量（原先复用 detection 阈值）

## 八、已知问题与技术债务

1. **test_doubao_api.py 解析逻辑 bug（未修复）**：使用 `'判断' in line` 匹配会误匹配包含"判断"词的行（如"无法判断是否在玩电脑游戏"）。不影响 `test_yolo_phone.py`（使用 `startswith` 严格匹配）。
2. **手部接触判断关键点选择待优化**：当前 `HAND_KEY_LANDMARKS = [0, 5, 9, 13, 17]` 仅检查手腕和 4 个 MCP 关节根部，未包含指尖（4/8/12/16/20）。拿手机时手指弯曲握住手机，指尖才是接触部位，关节根部可能在 bbox 之外。已提出 3 种优化方案（A/B/C）待用户确认实施。
3. **doubao-seed-2-0-mini 模型 ID 格式**：豆包 ARK API 需要完整格式 `doubao-seed-X-Y-name-日期`，简写格式（如 `doubao-seed-1.6-flash`）会返回 404。
4. **TRAE Sandbox 限制**：程序退出时可能尝试访问 NVIDIA 驱动缓存文件触发沙箱警告，非程序 bug，不影响功能验证。
