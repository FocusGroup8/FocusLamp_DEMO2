## 二、面部空间坐标估计器实现（上午）

### 2.1 需求
以摄像头为原点建立空间坐标系，估算用户面部相对摄像头的三维空间坐标。

### 2.2 坐标系约定
- 原点：摄像头光心（Phase 1 用画面几何中心近似）
- X 轴：水平向右（+ 右 / - 左）
- Y 轴：垂直向上（+ 上 / - 下）
- Z 轴：沿光轴朝向用户（+ 朝向用户）
- 单位：厘米 cm

### 2.3 算法核心
- **X/Y**：Face Mesh 鼻尖归一化坐标减原点，除以瞳距归一化值，乘瞳距物理先验（6.3cm）
- **Z**：Pose 鼻尖 z 减双肩中点 z，乘头长物理先验（23cm），反映低头/后仰姿态
- **distance_cm**：针孔模型 + FOV 假设估算绝对距离

### 2.4 新增文件
- `detectors/face_landmarker/mediapipe.py` — FaceLandmarker（478 关键点）
- `detectors/face_position_estimator/face_mesh_estimator.py` — 坐标估计算法
- `detectors/face_position_estimator/base.py` — FacePosition dataclass

## 三、4阶段渐进式重构（下午）

### 阶段1：抽出 MediaPipeAsyncProvider 通用基类

**目标**：消除 GestureDetector / PoseDetector / FaceLandmarker 三个 Provider 的重复模板代码。

**新增文件**：`detectors/base/mediapipe_async_provider.py`

**设计要点**：
- 通用方法：`_make_callback()`、`run(image)`、`close()`、`__enter__/__exit__`
- 抽象方法：`_submit_async(mp_image, timestamp_ms)` — 解决异步 API 方法名不一致（`recognize_async` vs `detect_async`）
- 抽象方法：`_extract_result(result)`、`get_detect_result()`

**关键 bug 修复**：GestureRecognizer 用 `recognize_async` 而非 `detect_async`，通过 `_submit_async` 抽象方法让子类各自指定。

**效果**：消除约 150 行重复代码，3 个 Provider 子类显著简化。
