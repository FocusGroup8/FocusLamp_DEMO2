# FocusLamp 算法接口文档

## 概述

本文档描述 FocusLamp 系统中各算法服务的核心输出数据。

***

## 1. 情绪类型 (Emotion)

**服务**: emotion-detector (端口 9004)

| 情绪类型      | 说明 |
| --------- | -- |
| happiness | 开心 |
| neutral   | 中性 |
| surprise  | 惊讶 |
| contempt  | 轻蔑 |
| disgust   | 厌恶 |
| fear      | 恐惧 |
| anger     | 愤怒 |
| sadness   | 悲伤 |

***

## 2. 投入度等级 (Engage Level)

**服务**: focus-detector (端口 9003)

| Level | Name           | 说明   |
| ----- | -------------- | ---- |
| 0     | Highly-Engaged | 高度投入 |
| 1     | Engaged        | 投入   |
| 2     | Barely-engaged | 轻微投入 |
| 3     | Not-Engaged    | 未投入  |

***

## 3. 专注度等级 (Focus Level)

**服务**: focus-detector (端口 9003)

| Level | Name             | 说明   |
| ----- | ---------------- | ---- |
| 0     | HighFocused      | 高度专注 |
| 1     | MediumFocused    | 中度专注 |
| 2     | LowFocused       | 低专注  |
| 3     | Neutral          | 中性   |
| 4     | LowDistracted    | 低度分心 |
| 5     | MediumDistracted | 中度分心 |
| 6     | HighDistracted   | 高度分心 |

***
