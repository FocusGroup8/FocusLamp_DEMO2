## 阶段流程

### 步骤1：自定义分区表

#### 1.1 背景说明

当前项目未包含自定义分区表，使用ESP-IDF默认分区。为支持LittleFS文件系统存储音频文件，需要创建自定义分区表。

**当前项目Flash配置**：
- 芯片：ESP32-P4
- PSRAM：已启用（HEX模式，200MHz）
- Flash大小：16MB（用户已确认）

#### 1.2 分区表设计

创建文件 `c:\Projects\Espressif_Projects\mipi_dsi\partitions.csv`：

```csv
# Name,   Type, SubType, Offset,   Size, Flags
# Note: if you have increased the bootloader size, make sure to update the offsets to avoid overlap
nvs,      data, nvs,     ,        0x6000,
phy_init, data, phy,     ,        0x1000,
factory,  app,  factory, ,        0x400000,
littlefs, data, spiffs,  ,        0xB80000,
```

**分区说明**：

| 分区名 | 类型 | 大小 | 说明 |
|--------|------|------|------|
| nvs | data/nvs | 24KB | 非易失性存储（比默认略大，预留配置空间） |
| phy_init | data/phy | 4KB | PHY初始化数据 |
| factory | app/factory | 4MB | 应用程序（MIPI DSI + 音频 + LVGL） |
| littlefs | data/spiffs | 11.5MB | 音频文件存储区 |

**存储容量验证**（11.5MB LittleFS 分区）：

| 用途 | 文件格式 | 单文件大小 | 可容纳数量 |
|------|----------|-----------|-----------|
| 录音文件 | WAV (16000Hz/16bit/单声道/30s) | ~938 KB | 12条 |
| 播放文件 | Ogg Opus (48kHz/单声道/30s) | ~60 KB | ~190首 |
| 混合使用 | 12条录音 + 多首播放 | - | 12条录音+约120首 |

> 16MB Flash 提供了充裕的音频存储空间，LittleFS 分区 11.5MB 可满足大量录音和音乐文件存储需求。

#### 1.3 操作指导

1. 创建分区表文件 `partitions.csv`（内容如上）
2. 通过 menuconfig 设置分区表路径：
   ```
   idf.py menuconfig
   → Partition Table
   → Partition Table → Custom partition table CSV
   → 输入: partitions.csv
   ```
3. 确认Flash大小配置：
   ```
   idf.py menuconfig
   → Serial flasher config
   → Flash size → 确认/调整为实际大小
   ```

> **确认闸门**：请确认Flash实际大小，以及11.5MB音频存储区是否满足需求。如需调整，请在确认时说明。

### 步骤2：ESP组件依赖添加

#### 2.1 需要添加的组件

基于文档01的选型分析，需要修改 `c:\Projects\Espressif_Projects\mipi_dsi\main\idf_component.yml`：

```yaml
dependencies:
  espressif/esp_lcd_st7701: ^2.0.2~2
  espressif/esp_lcd_touch_gt911: ^1.2.0
  espressif/esp_audio_codec: ^2.6.0
```

**组件说明**：

| 组件 | 版本 | 用途 | 大小影响 |
|------|------|------|----------|
| esp_lcd_st7701 | ^2.0.2~2 | 已有 | 无新增 |
| esp_lcd_touch_gt911 | ^1.2.0 | 已有 | 无新增 |
| esp_audio_codec | ^2.6.0 | **新增** | Ogg/Opus/WAV解码 + PCM编码 |

**esp_audio_codec 依赖链**：
- 依赖 `espressif/esp-adf-libs`（自动拉取）
- 通过 menuconfig 可按需启用/禁用各编解码器，减小最终固件体积

#### 2.2 操作指导

1. 修改 `idf_component.yml` 添加 `espressif/esp_audio_codec: ^2.6.0`
2. 执行 reconfigure 命令拉取组件：
   ```
   idf.py reconfigure
   ```
3. 验证组件是否成功下载：
   - 检查 `managed_components/` 目录下是否出现 `espressif__esp_audio_codec`
   - 检查 `dependencies.lock` 是否更新

> **确认闸门**：执行 `idf.py reconfigure` 后，请报告是否成功拉取组件。如遇网络或版本冲突问题，需根据错误信息调整。

### 步骤3：Kconfig 配置项扩展

#### 3.1 新增 Kconfig 选项

修改 `c:\Projects\Espressif_Projects\mipi_dsi\main\Kconfig.projbuild`，在现有 `menu "Example Configuration"` 末尾添加音频相关配置：

```kconfig
config EXAMPLE_ENABLE_AUDIO
    bool "Enable audio system (I2S microphone + speaker)"
    default n
    help
        Enable I2S audio subsystem with INMP441 microphone and MAX98357A amplifier.
        This adds I2S driver, LittleFS storage, and audio codec dependencies.

config EXAMPLE_AUDIO_SAMPLE_RATE
    int "Audio sample rate (Hz)"
    default 16000
    range 8000 48000
    depends on EXAMPLE_ENABLE_AUDIO
    help
        I2S audio sample rate in Hz. Common values: 8000, 16000, 22050, 44100, 48000.
        Default is 16000 (current verified value for I2S full-duplex).
        Note: 48kHz WAV recordings consume ~2.8MB per 30 seconds.

config EXAMPLE_AUDIO_I2S_NUM
    int "I2S port number"
    default 0
    range 0 2
    depends on EXAMPLE_ENABLE_AUDIO
    help
        I2S controller port number. ESP32-P4 has I2S port 0-2.
        Use 0 for default or set to I2S_NUM_AUTO for auto-allocation.

config EXAMPLE_AUDIO_LITTLEFS_PARTITION_LABEL
    string "LittleFS partition label"
    default "littlefs"
    depends on EXAMPLE_ENABLE_AUDIO
    help
        Label of the partition used for LittleFS audio file storage.
        Must match the partition name in partitions.csv.

config EXAMPLE_AUDIO_MOUNT_POINT
    string "LittleFS mount point"
    default "/audio"
    depends on EXAMPLE_ENABLE_AUDIO
    help
        File system mount point for audio files.

choice EXAMPLE_AUDIO_DEMO_MODE
    prompt "Audio demo mode"
    default EXAMPLE_AUDIO_DEMO_LOOPBACK
    depends on EXAMPLE_ENABLE_AUDIO
    help
        Select the audio demo to run.

    config EXAMPLE_AUDIO_DEMO_LOOPBACK
        bool "Loopback (mic → speaker)"
        help
            Record from microphone and immediately play through speaker.
            Tests the full I2S full-duplex path.

    config EXAMPLE_AUDIO_DEMO_RECORD_ONLY
        bool "Record only (mic → WAV file)"
        help
            Record from microphone and save as WAV file to LittleFS.

    config EXAMPLE_AUDIO_DEMO_PLAY_ONLY
        bool "Play only (Ogg file → speaker)"
        help
            Play an Ogg audio file from LittleFS through the speaker.

    config EXAMPLE_AUDIO_DEMO_FULL
        bool "Full demo (record + play + monitor)"
        help
            Complete audio system with recording, playback, and system monitoring.
endchoice
```

#### 3.2 操作指导

1. 将上述 Kconfig 内容追加到 `Kconfig.projbuild` 文件的 `endmenu` 之前
2. 执行 `idf.py reconfigure` 或 `idf.py menuconfig` 验证新选项出现
3. 在 menuconfig 中导航到：
   ```
   Example Configuration
   → Enable audio system (I2S microphone + speaker) [y]
   → Audio demo mode → 选择测试模式
   ```

> **确认闸门**：请在 menuconfig 中确认新增的音频配置项正确显示，并报告截图或选项列表。

### 步骤4：board_config.h 扩展

#### 4.1 新增 I2S 音频配置宏

在 `c:\Projects\Espressif_Projects\mipi_dsi\main\board_config.h` 末尾添加 Section 8：

```c
/*===========================================================================*/
/* Section 8: I2S Audio Configuration (INMP441 + MAX98357A)                  */
/*===========================================================================*/

/**
 * @name I2S Bus Configuration
 * @brief Full-duplex I2S bus shared by microphone and amplifier
 * @{
 */
#define BOARD_I2S_PORT           I2S_NUM_0       /*!< I2S controller port */
#define BOARD_I2S_ROLE           I2S_ROLE_MASTER /*!< ESP32-P4 as I2S master */
#define BOARD_I2S_SAMPLE_RATE    16000           /*!< Default sample rate in Hz (matches ESP-IDF official i2s_std example) */
#define BOARD_I2S_MCLK_MULTIPLE  I2S_MCLK_MULTIPLE_256 /*!< MCLK = 256 * sample_rate */
#define BOARD_I2S_DATA_BIT_WIDTH I2S_DATA_BIT_WIDTH_32BIT /*!< 32-bit required for INMP441 (24-bit data in 32-bit frame) */
/** @} */

/**
 * @name I2S GPIO Pins
 * @brief Pin assignments for I2S audio bus
 * @note BCLK and WS are shared between mic and amplifier
 * @{
 */
#define BOARD_I2S_BCLK_GPIO  GPIO_NUM_32 /*!< Bit clock (shared) - actual hardware: MAX98357A BCLK=32, INMP441 SCK=32 */
#define BOARD_I2S_WS_GPIO    GPIO_NUM_33 /*!< Word select / LRC (shared) - actual hardware: MAX98357A LRC=33, INMP441 WS=33 */
#define BOARD_I2S_DOUT_GPIO  GPIO_NUM_31 /*!< Data out → MAX98357A DIN - actual hardware: MAX98357A DIN=31 */
#define BOARD_I2S_DIN_GPIO   GPIO_NUM_30 /*!< Data in ← INMP441 SD - actual hardware: INMP441 SD=30 */
/** @} */

/**
 * @name I2S Slot Configuration (shared by TX and RX in full-duplex)
 * @brief In full-duplex mode, TX and RX must use the same slot configuration.
 * Both channels share BCLK/WS, so slot_mode and slot_mask must be identical.
 * Using PHILIPS format + MONO + LEFT.
 * @{
 */
#define BOARD_I2S_SLOT_MODE   I2S_SLOT_MODE_MONO  /*!< Mono mode */
#define BOARD_I2S_SLOT_MASK   I2S_STD_SLOT_LEFT   /*!< Left slot only */
/** @} */

/**
 * @name INMP441 Microphone Configuration
 * @{
 */
#define BOARD_MIC_CHANNEL     BOARD_I2S_SLOT_MODE /*!< Uses shared slot mode */
#define BOARD_MIC_SLOT_MASK   BOARD_I2S_SLOT_MASK /*!< INMP441 L/R=GND outputs on left slot */
/** @} */

/**
 * @name MAX98357A Amplifier Configuration
 * @note SD pin is floating (default) → mixed mode: outputs (Left/2 + Right/2)
 *       To output only left channel, connect SD to VDD through 100K resistor (>1.4V)
 *       To shut down, connect SD to GND (<0.16V)
 * @{
 */
#define BOARD_AMP_CHANNEL     BOARD_I2S_SLOT_MODE /*!< Uses shared slot mode */
#define BOARD_AMP_SLOT_MASK   BOARD_I2S_SLOT_MASK /*!< Use left slot for TX data */
/** @} */

/**
 * @name Audio DMA Configuration
 * @brief Validated values from radar_test reference
 * @{
 */
#define BOARD_AUDIO_DMA_BUF_COUNT  16   /*!< Number of DMA buffers */
#define BOARD_AUDIO_DMA_BUF_LEN    960  /*!< Samples per DMA buffer */
/** @} */

/**
 * @name LittleFS Storage Configuration
 * @{
 */
#define BOARD_AUDIO_PARTITION_LABEL  "littlefs" /*!< Partition label in partitions.csv */
#define BOARD_AUDIO_MOUNT_POINT      "/audio"   /*!< File system mount point */
/** @} */
```

#### 4.2 操作指导

1. 将上述内容追加到 `board_config.h` 文件末尾
2. 注意需在文件顶部添加 `#include "driver/i2s_std.h"` 以引用 I2S 相关枚举

> **确认闸门**：请确认 board_config.h 中的 I2S 配置宏与实际硬件引脚一致。特别注意 GPIO30/31/32/33 是否与项目中其他功能存在冲突。
