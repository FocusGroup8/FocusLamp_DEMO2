### 烧录与验收

先关闭灯头串口监视器，确认当前灯头端口。以下COM4仅为此前记录，需按实际端口替换，不能烧到基座。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/pixel-face/flash-head-app.ps1 -Port COM4
```

该脚本只写0x10000应用，不写LittleFS/NVS/分区表。加-Rollback可恢复优化前应用。
在正式工作台连接真实设备并恢复控制，打开pixel-faces.html，读取设备，点击“发送右侧优化稿”。独立47835预览默认只有模拟环境，不应把它当成已连接的正式工作台。

串口每约5秒输出[PIXEL_PERF]：窗口内完成绘制帧数、平均/最大绘制微秒（含LVGL锁等待）、内部RAM当前空闲/历史最低值、PSRAM当前空闲/最大连续块、Engine字节。
这不是屏幕VSync测量。模式切换附近的窗口可能只含部分时间，应在稳定优化模式下比较连续窗口。
分别记录：摄像头关闭、摄像头+网络传输开启、复杂表情连续切换；核对实际画面、左右眨眼、归中及帧耗时/内存。不能用编译通过替代并发验收。

## 当前限制（不作为完成项）

- SVG按6px网格采样，覆盖原稿6/12px定位；需真机对照细节。
- 静态几何已批量导入，不代表八角色动态全部验收。
- 网页时序演示使用收眼切换，尚非SVG逐点插值；头端表情暂为直接切换、保持到下次指令。
- 灯头暂为统一待机眨眼，未接各角色随机间隔、习惯动作、亮芯独立移动和自动归中时序。
- 视线目前移动眼体，不是原稿的独立亮芯动作，网页有说明。
- 未接云端情绪转发；摄像头/触摸原有逻辑仍可能改变当前表情。
- 未烧录、未连接实机发送命令；帧率、内存峰值、摄像头并发尚未实测。
- 原画布分配保持675KiB，未另建角色画布；生成结构常量在固件中，实际资源成本以编译映射为准。
