### 步骤1：I2S 驱动模块设计

#### 1.1 模块职责

文件 `c:\Projects\Espressif_Projects\mipi_dsi\main\audio\i2s_driver.h` 和 `i2s_driver.c` 已实现，职责：
- 封装 I2S 全双工通道的创建与初始化

- 提供 TX/RX 通道的独立启停控制
- **enable 前执行 DMA 预加载（preload）**确保有效数据立即输出
- 提供 TX 写入和 RX 读取的阻塞接口
- 管理驱动生命周期（init → enable → read/write → disable → deinit）
- deinit 不重复调用 disable（避免 "channel has not been enabled yet" 错误）

#### 1.2 接口设计

详见 `c:\Projects\Espressif_Projects\mipi_dsi\main\audio\i2s_driver.h` 当前代码。

#### 1.3 实现要点

##### 全双工通道创建（共享 std_cfg）

TX 和 RX 使用**完全相同的 `i2s_std_config_t`**，其中包括同时指定 dout 和 din 的 GPIO：

```c
esp_err_t i2s_audio_init(i2s_audio_handles_t *handles)
{
    // Step 1: Create channel pair (full-duplex)
    i2s_chan_config_t chan_cfg = I2S_CHANNEL_DEFAULT_CONFIG(BOARD_I2S_PORT, BOARD_I2S_ROLE);
    chan_cfg.dma_desc_num  = 16;   // 实际使用值
    chan_cfg.dma_frame_num = 960;  // 实际使用值
    chan_cfg.auto_clear   = true;
    ESP_ERROR_CHECK(i2s_new_channel(&chan_cfg, &handles->tx_handle, &handles->rx_handle));

    // Step 2: 使用同一个 std_cfg 配置 TX 和 RX
    // KEY: radar_test 使用相同的 i2s_std_config_t 同时初始化 TX 和 RX，
    // 其中 dout 和 din 同时指定在同一个 gpio_cfg 中
    i2s_std_config_t std_cfg = {
        .clk_cfg  = I2S_STD_CLK_DEFAULT_CONFIG(BOARD_I2S_SAMPLE_RATE),
        .slot_cfg = I2S_STD_PHILIPS_SLOT_DEFAULT_CONFIG(BOARD_I2S_DATA_BIT_WIDTH, I2S_SLOT_MODE_MONO),
        .gpio_cfg = {
            .mclk = I2S_GPIO_UNUSED,
            .bclk = BOARD_I2S_BCLK_GPIO,
            .ws   = BOARD_I2S_WS_GPIO,
            .dout = BOARD_I2S_DOUT_GPIO,  // → MAX98357A DIN
            .din  = BOARD_I2S_DIN_GPIO,   // ← INMP441 SD
        },
    };
    std_cfg.slot_cfg.slot_mask = I2S_STD_SLOT_LEFT;

    ESP_ERROR_CHECK(i2s_channel_init_std_mode(handles->tx_handle, &std_cfg));
    ESP_ERROR_CHECK(i2s_channel_init_std_mode(handles->rx_handle, &std_cfg));
    return ESP_OK;
}
```

##### TX/RX 共享配置的关键原因

在全双工模式下，TX 和 RX 通道共享 BCLK 和 WS 信号。ESP-IDF 官方示例（i2s_std duplex 模式）使用同一个 `i2s_std_config_t` 初始化两个通道，其中 dout 和 din 都在同一个 gpio_cfg 中指定。这确保了两个通道的 slot 配置、时钟配置完全一致，避免配置不一致导致的数据输出异常。

##### enable 前预加载（preload）

参考 ESP-IDF 官方 i2s_std 示例，在 enable TX 通道前用 `i2s_channel_preload_data()` 填充 DMA 缓冲区：

```c
esp_err_t i2s_audio_enable(const i2s_audio_handles_t *handles)
{
    // Preload TX DMA buffers before enabling
    int32_t preload_buf[64] = {0};
    size_t preload_bytes = sizeof(preload_buf);
    int preload_count = 0;
    while (preload_bytes == sizeof(preload_buf)) {
        ret = i2s_channel_preload_data(handles->tx_handle, preload_buf, sizeof(preload_buf), &preload_bytes);
        if (ret != ESP_OK) break;
        preload_count++;
    }
    // Enable TX first, then RX
    i2s_channel_enable(handles->tx_handle);
    i2s_channel_enable(handles->rx_handle);
    vTaskDelay(pdMS_TO_TICKS(100));  // 等待 I2S 外设稳定
    // Test read to verify RX...
}
```

##### INMP441 数据处理注意事项

| 要点 | 详情 |
|------|------|
| L/R 引脚 | 接地（GND），输出左声道数据 |
| 数据格式 | 24-bit 左对齐在 32-bit 帧中 |
| 位宽配置 | 必须使用 `I2S_DATA_BIT_WIDTH_32BIT` |
| slot_mask | `I2S_STD_SLOT_LEFT`（L/R=GND 时输出左声道） |
| slot_mode | `I2S_SLOT_MODE_MONO` |
| 格式 | Philips（I2S_STD_PHILIPS） |

##### MAX98357A 数据处理注意事项

| 要点 | 详情 |
|------|------|
| SD 引脚 | 悬空（NC），默认混合声道模式 |
| GAIN 引脚 | 悬空（NC），默认增益 9dB |
| 数据通道 | LEFT slot（与 INMP441 共用 LEFT slot） |
| 音量控制 | 需通过 PCM 数据缩放实现（无硬件音量接口） |

#### 2.2 回环诊断测试说明

这是区分**软件问题**和**硬件问题**的关键测试：

1. 创建独立的 I2S 通道对，设置 `din = dout`（GPIO31）
2. 关闭 auto_clear（`auto_clear = false`）
3. 预加载已知测试模式（0x40000000/0xC0000000 交替）
4. TX 写入后 RX 读取并比较

| 回环结果 | 含义 | 行动 |
|----------|------|------|
| 匹配 > 80% | I2S 外设正常 → **硬件问题**（MAX98357A 电源、连接、扬声器） | 检查硬件连接 |
| 匹配 30-80% | 数据存在但错位或损坏 | 检查时序/DMA 配置 |
| 匹配 < 30% | I2S 外设未正确输出 → **软件/驱动问题** | 检查代码配置 |

**实际验证结果：99.8% 匹配**，确认 I2S 外设软件配置正确。

### 步骤4：项目实施中遇到的坑与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 程序崩溃（Load access fault） | `CONFIG_EXAMPLE_RUN_I2S_TEST` 开启时 `gui == NULL`，对 NULL 指针解引用 | 添加 `if (gui == NULL)` 检查 |
| 扬声器无声音 | GPIO 配置与实际硬件不匹配（代码用 radar_test 的 GPIO） | 按实际硬件改为 BCLK=32, WS=33, DOUT=31, DIN=30 |
| 扬声器仍无声音 | MAX98357A 功放电源未接通 | 接通 5V 电源 |
| 麦克风数据全零 | INMP441 输出 24-bit 数据左对齐在 32-bit 帧中，原配置 16-bit 导致时序错位 | 改为 32-bit 数据宽度 + LEFT slot |
| 麦克风数据全零 | 原配置读取 RIGHT slot，INMP441 L/R=GND 时输出 LEFT slot | slot_mask 改为 LEFT |
| 全双工测试栈溢出 | 栈上分配两个 int32_t[1024]（各 4KB），超过任务栈 | 改为堆分配（malloc/free） |
| sizeof(pointer) 陷阱 | 缓冲区从数组改为指针后 sizeof 返回指针大小 | 显式传递缓冲区大小 |
| i2s_channel_disable 重复调用 | disable 后 deinit 再次 disable | deinit 不调用 disable，直接 del_channel |
| 回环测试 0% 匹配 | auto_clear=true + preload 全零数据 + RX 读取时机过早 | 关闭 auto_clear、预加载真实测试模式、多次 RX 读取 |

## 全局约束

- I2S 驱动模块仅负责硬件抽象层，不包含音频编解码逻辑
- 全双工模式下 TX 和 RX 必须使用相同的 std_cfg（共享 BCLK/WS）
- TX/RX 的 dout 和 din 在同一个 gpio_cfg 中指定
- enable 前必须执行 preload 确保 DMA 缓冲区填充
- 所有引脚定义使用 `board_config.h` 中的宏，禁止硬编码
- 禁止直接修改 sdkconfig
- deinit 中不重复调用 disable（del_channel 内部会处理）
