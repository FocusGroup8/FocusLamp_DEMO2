### 步骤2：麦克风录音功能

#### 2.1 录音模块设计

创建 `c:\Projects\Espressif_Projects\mipi_dsi\main\audio\recorder.h` 和 `recorder.c`：

```c
#pragma once

#include "esp_err.h"
#include "audio/i2s_driver.h"

/**
 * @brief WAV file header structure (44 bytes)
 */
typedef struct {
    // RIFF header
    char     riff_tag[4];       // "RIFF"
    uint32_t riff_size;         // File size - 8
    char     wave_tag[4];       // "WAVE"
    // fmt sub-chunk
    char     fmt_tag[4];        // "fmt "
    uint32_t fmt_size;          // 16 (PCM)
    uint16_t audio_format;      // 1 (PCM)
    uint16_t num_channels;      // 1 (mono)
    uint32_t sample_rate;       // 16000
    uint32_t byte_rate;         // sample_rate * num_channels * bits_per_sample / 8
    uint16_t block_align;       // num_channels * bits_per_sample / 8
    uint16_t bits_per_sample;   // 16
    // data sub-chunk
    char     data_tag[4];       // "data"
    uint32_t data_size;         // PCM data size in bytes
} wav_header_t;

typedef enum {
    RECORDER_IDLE,
    RECORDER_RECORDING,
    RECORDER_STOPPING,
} recorder_state_t;

/**
 * @brief Start recording from microphone to WAV file
 *
 * Creates a new WAV file on LittleFS and starts a FreeRTOS task
 * that reads I2S RX data and writes to the file.
 *
 * @param i2s_handles  I2S handles with RX channel
 * @param filename     Output filename (e.g., "/audio/rec_001.wav")
 * @param max_duration Maximum recording duration in seconds (0 = unlimited)
 * @return ESP_OK on success
 */
esp_err_t recorder_start(const i2s_audio_handles_t *i2s_handles,
                         const char *filename,
                         uint32_t max_duration);

/**
 * @brief Stop recording and close WAV file
 *
 * Writes final WAV header with correct data size.
 *
 * @return ESP_OK on success
 */
esp_err_t recorder_stop(void);

/**
 * @brief Get current recorder state
 */
recorder_state_t recorder_get_state(void);
```

#### 2.2 WAV 文件格式说明

WAV 文件头固定 44 字节，关键参数（当前测试阶段使用 16000 Hz）：

| 字段 | 值 | 说明 |
|------|-----|------|
| audio_format | 1 | PCM 格式（无压缩） |
| num_channels | 1 | 单声道 |
| sample_rate | 16000 | 当前测试采样率（后续可按需调整为 48000） |
| bits_per_sample | 16 | I2S 总线为 32-bit，有效数据为 24-bit，WAV 存储为 16-bit PCM |
| byte_rate | 32000 | 16000 * 1 * 16 / 8 |
| block_align | 2 | 1 * 16 / 8 |

> **注意**：INMP441 输出 24-bit 数据左对齐在 32-bit 帧中，I2S 总线必须配置为 32-bit 数据宽度。
> WAV 文件存储时，需要从 32-bit 样本中提取有效数据位（右移获取 16-bit PCM）。

#### 2.3 录音实现流程

```
1. 创建 WAV 文件，写入 44 字节占位头部
2. 创建录音任务 (recorder_task)
3. 在任务循环中：
   a. i2s_channel_read(rx_handle, ...) → 读取 PCM 数据
   b. fwrite() → 写入文件
   c. 累计已录制时长
   d. 检查是否达到 max_duration 或收到停止信号
4. 收到停止信号后：
   a. 回写 WAV 头部的 data_size 和 riff_size
   b. 关闭文件
   c. 更新状态为 IDLE
```

#### 2.4 录音参考代码（基于 INMP441 例程适配）

参考 `c:\Projects\Espressif_Projects\mipi_dsi\example\INMP441 microphone\` 中的 Arduino 例程，关键差异：

| Arduino 例程 | ESP-IDF 新驱动 | 说明 |
|-------------|---------------|------|
| `i2s_driver_install()` | `i2s_new_channel()` + `i2s_channel_init_std_mode()` | 新旧驱动 API 不同 |
| `i2s_pop_sample()` | `i2s_channel_read()` | 批量读取替代逐样本读取 |
| `I2S_BITS_PER_SAMPLE_32BIT` | `I2S_DATA_BIT_WIDTH_32BIT` | INMP441 输出 24-bit 左对齐在 32-bit 帧中，必须用 32bit |
| `I2S_CHANNEL_FMT_ONLY_RIGHT` | `I2S_STD_SLOT_LEFT` + `I2S_SLOT_MODE_MONO` | 新驱动声道配置方式不同；INMP441 L/R=GND 输出 LEFT slot |

**已验证**：INMP441 的原始数据是 32-bit 的（高 24-bit 为有效数据，低 8-bit 为 0），必须使用 32-bit slot 位宽。已验证 32-bit Philips + MONO + LEFT 配置下数据正确，麦克风 RMS 值正常。

> **确认闸门**：确认 INMP441 在 16bit 模式下数据是否正确。如不正确，需切换到 32bit 模式并手动提取数据。

**48kHz 统一采样率说明**：当前 I2S 驱动层已完成 16000 Hz 采样率下的全双工验证。后续录音和播放功能可选择升级到 48kHz 统一采样率，此时 WAV 录音文件大小约 2.8MB/30s，11.5MB LittleFS 分区可容纳约 4 条 30s 录音。目前 16000 Hz 下约 0.92MB/30s，可容纳约 12 条。

```c
 * @brief Stop playback
 */
esp_err_t player_stop(void);

/**
 * @brief Get current player state
 */
player_state_t player_get_state(void);

/**
 * @brief Set playback volume (0-100)
 */
esp_err_t player_set_volume(int volume_percent);
```

#### 3.2 Ogg 解码流水线（实际实现）

**重要变更**：由于 ESP 的 `esp_audio_codec` Opus 实现不稳定（多次崩溃），改用更稳定的原生 Opus API。

**实际技术方案**：
```
解码器库：esphome/micro-opus (^0.4.1)
文件名：player.cpp/h（C++ 文件）
API：micro_opus::OggOpusDecoder（原生 C++ 类）
额外处理：48kHz → 16kHz 软件重采样
```

**解码流程**：
```
1. 打开 LittleFS 上的 Ogg Opus 文件
2. 创建 OggOpusDecoder 实例（C++ 类）
3. 解码循环:
   a. fread() → 从文件读取原始 Ogg 数据到 input_buf
   b. decoder.decode(ogg_data, pcm_16bit)
   c. resample_48k_to_16k() → 软件降采样（Opus 输出48kHz）
   d. 转换为 32-bit I2S 格式（左对齐）
   e. i2s_channel_write(tx_handle, pcm_32bit, ...) → 输出到功放
   f. 重复直到文件结束
4. 关闭解码器和文件
```

**关键差异说明**：
- **文件名变化**：player.c → player.cpp（需要 extern "C" 声明以兼容 C 文件调用）
- **解码器库变化**：esp_audio_codec → micro-opus（稳定性更好）
- **新增重采样**：48kHz → 16kHz（Opus 标准输出48kHz，I2S 配置为16kHz）
- **初始化简化**：无需 esp_audio_dec_register_default()（micro-opus 自包含）

**依赖管理**（idf_component.yml）：
```yaml
dependencies:
  esphome/micro-opus: "^0.4.1"  # Native OGG Opus decoder (stable)
```

#### 3.3 采样率方案

当前 I2S 驱动层已在 **16000 Hz** 采样率下完成全双工验证（匹配 ESP-IDF 官方 i2s_std 示例）。后续录音和播放功能可根据需求保持 16000Hz 或升级到 48000Hz：

| 方案 | 采样率 | WAV 大小(30s) | 分区容量 | 说明 |
|------|--------|--------------|----------|------|
| 当前 | 16000 Hz | ~0.92 MB | ~12 条 | 已验证通过 |
| 可选升级 | 48000 Hz | ~2.8 MB | ~4 条 | 音质更高，但需要更大处理能力 |

优势：
- 当前 16000 Hz 已充分验证，代码稳定
- 录音和播放可无缝切换（同一采样率时无需重新配置 I2S 时钟）
- 如升级到 48kHz，仅需修改 `BOARD_I2S_SAMPLE_RATE` 宏

#### 3.4 MAX98357A 音量控制

MAX98357A 没有硬件音量控制接口，需通过软件方式实现：

1. **PCM 数据缩放**：在写入 I2S 前对 PCM 采样值乘以缩放系数
2. **I2S 内置增益**：部分 I2S 驱动支持软件增益（需查证 ESP-IDF 是否支持）
3. **MAX98357A GAIN 引脚**：硬件增益选择（15dB/12dB/9dB/6dB），需物理接线，本项目 GAIN=NC = 9dB

推荐使用方案1（PCM 数据缩放），在 `player.c` 中实现：

```c
// 音量缩放（0-100% → 0.0-1.0）
static float s_volume_scale = 1.0f;

esp_err_t player_set_volume(int volume_percent)
{
    if (volume_percent < 0) volume_percent = 0;
    if (volume_percent > 100) volume_percent = 100;
    s_volume_scale = volume_percent / 100.0f;
    return ESP_OK;
}

// 在写入I2S前缩放PCM数据（注意：I2S 使用 int32_t 非 int16_t）
static void scale_pcm_samples(int32_t *samples, size_t count, float scale)
{
    for (size_t i = 0; i < count; i++) {
        samples[i] = (int32_t)(samples[i] * scale);
    }
}
```

#### 4.1 状态机设计

```
状态转换:
```

```
audio_manager
  ├── i2s_driver      (I2S 通道控制)
  ├── recorder        (录音功能)
  ├── player          (播放功能)
  └── audio_storage   (LittleFS 文件管理)
```
