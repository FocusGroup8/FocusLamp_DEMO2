# 久坐提醒：本地合成语音

本批改为嵌入现成的中文合成音频，不再用云端 `listen/detect` 请求久坐播报。未编译、未烧录，尚未实机验收。

## 行为

- 普通、专注模式：雷达持续在位满 60 秒后提醒；不依赖云端播报服务。
- 正在对话时暂缓，结束对话后提交，不重新等 60 秒。
- 每个在位周期只尝试一次，失败不自动重播。离开、数据过期或模式变更清状态。
- 陪伴模式不触发久坐提醒，保留原规则。
- 本地音频约 5.4 秒。播放期间暂停唤醒识别、阻止麦克风音频上行，不支持打断本地提醒。

## 实现范围

`main/audio/sedentary_reminder.wav`：16kHz 单声道 PCM16，172866 字节音频数据，由 `audio_preview/sedentary_reminder_huihui.wav` 复制。原用户录音不修改。

`main/local_reminder.c`：解析 WAV，独立任务播放，不阻塞雷达计时；开始前复查周期、模式、对话和雷达在位。

`audio_bridge`：PCM16 分块转 32-bit I2S、复用音量与 AEC 参考逻辑；TX 写入互斥，云端 OPUS 不混入本地输出；已出队旧帧用代次失效处理。本地 PCM 不进入云端解码队列。

`wake_word_engine`：本地与普通暂停分别持有，云端 TTS_STOP 不会释放本地暂停。

## 状态口径

- `sedentary_submitted`：本地播放请求入队，不等于播完。
- `sedentary_local_output_done`：整段 PCM 与大于一圈 DMA 容量的静音尾部全部写入成功。静音持续写入用于实际排空旧音频，不用固定睡眠或回调字节计数判断。
- 不把该字段视为扬声器出声、人听到了或文案声学完整的证明，必须实听验收。
- `sedentary_text_observed`：保留兼容，固定为 false；云端句子不再用作本地提醒确认。

## 烧录后验证（由用户执行）

1. 启动出现 `LOCAL_REMINDER: Embedded PCM16 ready: 172866 bytes, 16kHz mono`。
2. 保持雷达在位、无对话，满 60 秒出现 `local clip queued`，随后 `local playback started`。
3. 应听到「你已经坐了很久，请站起来活动活动吧」。确认句尾完整、音量正常；结果应为 `local output result=ESP_OK`，Summary 中 `local_output_done=1`。
4. 继续不离开两分钟，不应重复提醒；离开后重新在位满 60 秒，应能再次提醒。
5. 在 60 秒到达前开始对话，应暂缓；结束对话再提醒。播放后重新唤醒，验证正常对话恢复。
6. 雷达采样年龄超过 3 秒仍按原规则清计时。若不触发，先看 `radar_fresh/present/sedentary`，不改阈值掩盖停流。

旧 `tools/test_sedentary_prefix.ps1` 仅测试云端注入，与本地提醒无关，不作为本批验收步骤。
